# Via Valpantena 135 — Quinto (Verona)

Questo repository raccoglie tutta la documentazione strategica, tecnica e finanziaria per l'acquisto, la ristrutturazione, il frazionamento e la vendita/locazione dell'immobile sito in **Via Valpantena 135, Quinto (VR)**, con l'obiettivo di massimizzare i benefici fiscali, ridurre i rischi e ottimizzare le risorse disponibili.

## Strategia in Sintesi

```
1. ACQUISTA con agevolazioni Prima Casa / Under 36  →  risparmio imposte
2. RISTRUTTURA con Superbonus + Bonus Ristrutturazione  →  risparmio 50–70% sui lavori
3. FRAZIONA in 2–4 unità indipendenti  →  +30–60% valore di mercato
4. MONETIZZA: vendi 1–2 unità + affitti le restanti  →  rendita passiva + recupero capitale
```
