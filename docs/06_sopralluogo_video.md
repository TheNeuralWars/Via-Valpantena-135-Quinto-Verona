## 2. Indice degli Ambienti da Documentare

Utilizzare questa checklist per verificare che tutti gli ambienti siano stati ripresi nei video o aggiungere note per le aree mancanti.

### Esterni
- [ ] **Facciata principale** — stato intonaco, finestre, porte d'ingresso
- [ ] **Facciata posteriore / laterali** — crepe, umidità, infiltrazioni visibili
- [ ] **Tetto** — stato del manto di copertura, grondaie, pluviali
- [ ] **Aree esterne** — giardino, cortile, recinzioni, accessi carrabili
- [ ] **Garage / box / pertinenze**

### Piano Terra
- [ ] **Ingresso / corridoio**
- [ ] **Soggiorno / living**
- [ ] **Cucina** — stato impianto idraulico, scarichi, piastrelle
- [ ] **Bagno/i** — stato sanitari, piastrelle, impianto idraulico
- [ ] **Camera/e da letto**
- [ ] **Vano scale interni**

### Primo Piano (se presente)
- [ ] **Tutti gli ambienti** (indicare numero vani)
- [ ] **Soffitte / sottotetto** — altezze, struttura, umidità

### Locali Tecnici
- [ ] **Cantina / seminterrato**
- [ ] **Locale caldaia / impianto termico**
- [ ] **Quadro elettrico** — anno apparente, tipo impianto
